Crea la struttura di un sito web di un AGRITURISMO (reale o di tua invenzione), il sito web deve contenere le seguenti pagine:
  • INDEX: Homepage di accesso al sito
  • PAGINA CAMERE: Elenco delle camere disponibili
  • PAGINA CLIENTE PRENOTAZIONI: Form di prenotazione per le camere disponibili
  • PAGINA GESTORE DISPONIBILITA': Elenco delle disponibilità e prenotazioni effettuate
Inoltre il sito web deve avere le seguenti caratteristiche:
  • Un menu di navigazione comune tra le pagine
  • Un footer comune tra le pagine con i contatti dell'agriturismo
Per curare la grafica del sito utilizza il framework: W3.CSS.

Consegna il sito web in una cartella compressa contenente tutti i file necessari al funzionamento del sito.
