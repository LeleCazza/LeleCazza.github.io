Portale Accessi per un Festival.

Stai programmando il sistema di verifica dei biglietti all'ingresso di un festival musicale. Imposta le variabili eta = 22 e ha_patente = True (che rappresenta il possesso di un documento valido).
Il software deve calcolare e stampare valori booleani (True/False) per verificare se:
  1. L'utente è maggiorenne (18 anni o più).
  2. L'utente ha diritto allo sconto speciale (riservato agli under 18 o agli over 65).
  3. L'utente può accedere all'area VIP (consentito solo se è maggiorenne E possiede un documento valido).
  4. L'utente è sprovvisto di documento.
Funzioni e Operatori da utilizzare: print(), >= e < (confronto), and, or, not (logici).

OUTPUT ESERCIZIO:
È maggiorenne?: True
Ha diritto allo sconto?: False
Può accedere all'area VIP?: True
È sprovvisto di documento?: False
